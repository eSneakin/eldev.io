# eldev.io

Portafolio personal de Enmanuel López para presentar proyectos.

## Proyectos

- **CoinLyzer & Priorix Mobile:** Finanzas personales y organización de tareas en Flutter.
- **Tracklet:** Aplicación nativa para controlar Spotify y usar widgets en macOS.
- **RentCar:** Plataforma web para administrar vehículos, clientes, inspecciones, rentas y reportes.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Diseño responsive sin dependencias externas

## Ejecución local

Abre `index.html` directamente o usa un servidor local:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.

## Estructura

```text
index.html   Contenido y estructura
styles.css  Diseño y adaptación responsive
script.js   Interacciones y animaciones
images/     Logos e identidad visual
```
